# MiniBoard CLI

MiniBoard is a deliberately small, dependency-free Node.js command-line task
board. This repository doubles as a compact example of feature-branch
development and iterative delivery.

## Requirements

- Node.js 20 or newer

## Quick start

```powershell
npm test
npm start -- --help
```

The first iteration only provides the executable shell. Task storage and
reporting are added in later feature branches.
